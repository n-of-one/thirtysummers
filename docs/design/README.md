# Design

The design of thirtysummers, one document per aspect. Each document says
what the game is in that respect, in prose, so it can be read in one
sitting to recall the current idea. They are not minutes: the thinking
behind them, the options that were considered and what was parked, stays
in [../BRAINSTORM.md](../BRAINSTORM.md). Where a document here disagrees
with [../DESIGN.md](../DESIGN.md), the document here is newer and wins.

| Document | Aspect |
|---|---|
| [map-arc.md](map-arc.md) | One map from the first summer to the road out: lives, domains, structures, the town, the floor, generations. |
| [summer.md](summer.md) | One summer: the two bars, barriers and their keys, the resource ladder, tools, improvements, getting it home, and the five-summer test. |
| [winter.md](winter.md) | Between summers: what comes back and what wears, the winter screen, upkeep, the shop, the family. |

New documents are added as each topic of the brainstorm is refined: the
summer (stats, resources, the map without you), winter, the lineage.
